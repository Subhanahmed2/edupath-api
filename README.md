# Edu Path AI - backend (deployment copy)

FastAPI backend of the Edu Path final year project (Riphah International University): field recommendation
(XGBoost + SHAP), career questions (rules + LLM) and program recommendation (RAG).
Generated by deploy/build.py from the project - edit the project, not this copy.

- `GET /health` - status · `GET /docs` - API documentation
- Render: build `pip install -r requirements.txt`, start `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`
- Settings come from environment variables (never committed): `DATABASE_URL` (Neon PostgreSQL),
  `EDUPATH_SMTP_*` (sign-up emails), `EDUPATH_LLM=groq` + `GROQ_API_KEY`, `EDUPATH_EMBEDDINGS=tfidf`.
